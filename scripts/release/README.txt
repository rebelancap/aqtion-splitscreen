AQtion splitscreen @VERSION@ - local splitscreen (up to 8 players) with gamepads for AQtion (Steam).
Windows: put q2pro-splitscreen.exe in your AQtion folder (Steam: right-click AQtion -> Manage ->
Browse local files) and start it. Your settings live in the splitscreen folder it creates there.
Linux / Steam Deck: put q2pro-splitscreen next to q2pro there (chmod +x if needed) and run it, or
add it to Steam (Desktop mode: Add a Non-Steam Game; on Steam Deck it then shows in Game mode).
Steam's AQtion files are not changed. To uninstall, delete the program and the splitscreen folder.
Pads: hold A to join, hold Back+Start to leave, Start opens your menu (Start on player 1's pad at
the main menu = splitscreen settings and "Start multiplayer game").
Full README, changelog and source code: https://github.com/rebelancap/aqtion-splitscreen
